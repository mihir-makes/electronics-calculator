Ref. Electronic Calculators

A collection of small calculators for embedded & electronics work

Voltage Divider

Given Vin and resistor values, find Vout, ratio, current and ADC count. Basic and multi-resistor High Voltage modes.

Reverse ADC Calculator

Given resistor values and an ADC raw reading, back-calculate the actual Vin at the divider input.

SMD Resistor Code

Decode 3-digit, 4-digit, R-notation, and EIA-96 SMD resistor markings into ohms.

Capacitor Code

Decode ceramic capacitor 3-digit codes, tolerance letters, and direct p/n/u notation.

Modbus RTU Frame Analyzer

Paste a raw RTU frame — decode slave ID, function code, request/response direction, fields, and verify CRC.

Modbus Response Analyzer

Decode response register data as signed, unsigned, hex, ASCII, binary, or wide 32/64-bit int & float values, with adjustable register grouping.

Boost Converter Power Stage

TI SLVA372 equations — duty cycle, ripple current, max switch current, and inductor selection.

Op-Amp Calculator

Inverting, non-inverting, and difference amp gain/output calculators.
